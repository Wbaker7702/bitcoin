Supported Providers:
====================

Provider          String ID      Description
─────────────────────────────────────────────────────────
MetaMask         "metamask"      Browser-based wallet
Coinbase Wallet  "coinbase"      Coinbase wallet app


Connection Object:
==================

{
  provider:        ExternalWalletProvider (enum)
  address:         string (wallet address)
  session_id:      string (unique identifier)
  is_connected:    bool (connection status)
  connected_time:  int64_t (timestamp)
  metadata:        map<string, string> (extensible)
}
