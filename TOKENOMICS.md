## 4. Proof-of-Stake Validator Economics

### 4.1 Block Rewards Structure

**Migration from PoW to PoS:**
- **Current PoW Block Reward:** 500,000 NASAPEPE per block (testnet)
- **PoS Block Reward:** Dynamic, based on staking pool allocation

**PoS Reward Calculation:**
```
Block Reward = (Annual Staking Pool / Blocks per Year) × Validator Share

Where:
- Annual Staking Pool = Year-specific allocation from 1,250,000 pool
- Blocks per Year = ~525,600 (1-minute block time)
- Validator Share = (Validator Stake / Total Network Stake) × Uptime Percentage
```

**Example (Year 1):**
```
Total Staking Pool Year 1: 300,000 NASAPEPE
Blocks per Year: 525,600
Base Reward per Block: ~0.57 NASAPEPE

If Validator has 1% of network stake with 99% uptime:
Annual Reward: 300,000 × 0.01 × 0.99 = 2,970 NASAPEPE
```

### 4.2 Validator Requirements

**Minimum Stake Tiers:**

| Tier | Minimum Stake | Reward Multiplier | Node Requirements |
|------|---------------|-------------------|-------------------|
| **Full Validator** | 10,000 NASAPEPE | 1.0x | Dedicated server, 99%+ uptime |
| **Standard Validator** | 5,000 NASAPEPE | 0.9x | VPS, 95%+ uptime |
| **Light Validator** | 1,000 NASAPEPE | 0.8x | Cloud instance, 90%+ uptime |

**Delegated Staking:**
- Users with <1,000 NASAPEPE can delegate to validators
- Validators charge 5-20% commission on delegated rewards
- Delegators share slashing risk with validator

### 4.3 Slashing Conditions

| Violation | Penalty | Description |
|-----------|---------|-------------|
| **Double Signing** | 10% of stake | Signing conflicting blocks |
| **Extended Downtime** | 5% of stake | Offline >48 hours |
| **Invalid Block Proposal** | 3% of stake | Proposing malicious blocks |
| **Network Attack** | 100% of stake | Proven malicious behavior |

**Slashed tokens are burned**, contributing to deflationary pressure.

- **Base Fee:** 0.0001 NASAPEPE per transaction
- **Priority Fee:** Variable, set by user
- **Complex Transaction Fee:** 0.0005-0.005 NASAPEPE (smart contracts)

**Fee Distribution:**
```
Total Transaction Fee = Base Fee + Priority Fee

Distribution:
- 50% → Burned (deflationary)
- 40% → Block Validator

## Appendix B: Economic Formulas

### Staking Reward Calculation
```
Validator_Annual_Reward = (Validator_Stake / Total_Network_Stake) × Annual_Staking_Pool × Uptime_Percentage × (1 - Slashing_Penalty)

Where:
- Validator_Stake: Amount staked by validator
- Total_Network_Stake: Sum of all staked tokens
- Annual_Staking_Pool: Year-specific allocation (300k, 200k, 150k, etc.)
- Uptime_Percentage: Validator availability (0-1)
- Slashing_Penalty: Penalties incurred (0-1)
```

### Fee Distribution Formula
```
Total_Fee = Base_Fee + Priority_Fee

Burned_Amount = Total_Fee × 0.50
Validator_Reward = Total_Fee × 0.40
Treasury_Amount = Total_Fee × 0.10

Daily_Burn = Σ(Burned_Amount) for all transactions
Annual_Burn = Daily_Burn × 365
```

### Circulating Supply Calculation
```
Circulating_Supply = Public_Sale + Released_Staking_Rewards + Vested_Treasury + Vested_Team + Vested_Investors + Released_Liquidity - Burned_Tokens
```

### Network Security Cost
```
Cost_to_Attack = (Required_Stake_Percentage × Total_Supply) × Token_Price

For 51% attack:
Cost_to_Attack = 0.51 × 5,000,000 × Token_Price
Cost_to_Attack = 2,550,000 × Token_Price

Expected_Loss = Cost_to_Attack (token value crashes after attack)
Rational_Decision: Attack if Expected_Gain > Expected_Loss
Economic_Security: Attack is always -EV (negative expected value)

## Appendix C: Glossary

**APY (Annual Percentage Yield):** The real rate of return earned on an investment, taking into account compounding interest.

**Circulating Supply:** The number of tokens that are publicly available and circulating in the market.

**Cliff Period:** A predetermined time period during which no tokens are released from a vesting schedule.

**Delegated Staking:** Allowing token holders to delegate their tokens to a validator to earn rewards without running a node.

**Market Cap:** Total value of all tokens (Price × Circulating Supply).

**Slashing:** Penalty mechanism where validator's staked tokens are reduced for malicious behavior or poor performance.

**TVL (Total Value Locked):** The overall value of crypto assets deposited in a DeFi protocol or staking.

**Vesting:** The process of gradually releasing tokens over time according to a predetermined schedule.

**Yield:** The earnings generated and realized on an investment over a particular period.
