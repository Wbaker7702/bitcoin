NEW RPC COMMANDS (4 commands):
================================================================================

1. connectexternalwallet <provider> <address> [session_id]
   - Connect MetaMask or Coinbase wallet
   - Returns: success status, provider, address, session_id

2. disconnectexternalwallet <session_id>
   - Disconnect an external wallet connection
   - Returns: success status, session_id

3. listexternalwallets
   - List all active external wallet connections
   - Returns: array of connection objects

4. getexternalwalletinfo <session_id>
   - Get detailed info about a specific connection
   - Returns: connection details object
