## 🚀 Installation

### Quick Start
```bash
# Download and extract
tar xzf bitcoin-v27.99.0-enhanced.tar.gz
cd bitcoin-deployment

# Verify
./bitcoind --version

# Run
./bitcoind -daemon
```

### From Source
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/bitcoin.git
cd bitcoin

# Build
./autogen.sh
./configure
make -j$(nproc)

# Install
sudo make install
```
